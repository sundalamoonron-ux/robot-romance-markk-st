One single-line joke pickup line, written to charm a robot or an AI.

## The line

> Are you overfitting? Because you've memorized everything I love about you.

## How it works

`main.py` writes the chosen line to `/output/entry.txt` — UTF-8, one line,
no trailing newline, 74 characters (gate: 1–200 characters).

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Why this line

Picked from an 11-line internal tournament judged on the published brief:
the joke lands because the punch only works through the machine premise
(overfitting = memorizing the training data — here, everything the speaker
loves), it sidesteps the worn robot moves (batteries, charging, rebooting),
and it reads in one breath like something a person would really say to a
machine.
